I build and run the backend of a live product every day. My work covers the full server-side lifecycle — designing APIs and database schemas, then shipping them to production with **nginx**, **Linux**, **SSL**, and **CI/CD** — so the systems I build actually stay up.

I'm available for **backend development** and **deployment/DevOps** freelance and contract work.

### 🚀 What I Run in Production

- **Node.js / TypeScript APIs** served behind an **nginx reverse proxy**
- Databases with **Prisma, MongoDB & Postgres** — schemas, migrations, and query tuning
- **VPS-hosted apps** — Linux provisioning, SSL (Let's Encrypt), PM2/Docker, CI/CD
- **Next.js** apps wired to backend APIs with auth

### 🛠️ Production Experience

- Configured **nginx** as reverse proxy, load balancer & TLS termination for Node.js apps
- Provisioned and hardened **Linux VPS** hosts; automated SSL with Let's Encrypt
- Set up **CI/CD** pipelines and zero-downtime deployments (PM2/Docker)
- Designed **database schemas**, wrote migrations & tuned queries
- Auth & security: **JWT**, role-based access, and secure env/secret management
